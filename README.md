# 麦氏乡村网站系统

一个专为麦氏家族打造的乡村网站系统，包含族谱大树图谱、前台博客、文章页、公告、留言、友链、用户登录、个人中心和后台管理。

## 功能列表

### 前台功能

- **文章浏览**：首页文章列表、文章详情页、封面图、摘要、分类筛选、全文搜索
- **五种显示模式**：默认模式、传统列表、固定网格卡片、瀑布流、杂志混合布局，仅管理员可在后台切换
- **文章互动**：点赞、收藏、分享功能（登录用户同步到服务器，未登录用户使用本地存储）
- **个人中心**：用户注册/登录后可在个人中心查看"我的投稿""我的点赞""我的收藏"
- **投稿系统**：前台用户可投稿文章，管理员审核通过后发布
- **留言系统**：主页留言、文章留言、表情选择、关键词审核、分页显示
- **友链系统**：友链展示、用户可提交友链申请、后台审核
- **关于页面**：后台可配置的 HTML 关于页面，含联系方式与赞助支持
- **公告系统**：首页公告展示、文章页公告展示
- **广告管理**：8 个预设广告位，支持图片/HTML/文字三种广告类型，后台统一管理
- **多语言**：中文/英文切换，全站文本国际化
- **主题定制**：绿色/蓝色/紫色主题色切换
- **暗黑模式**：白天/夜间模式切换，防闪烁加载
- **响应式设计**：适配桌面端和移动端，移动端底部导航栏

### 后台管理功能

- **仪表盘**：总览统计（文章数、已发布、草稿、待审核、浏览量、分类数、标签数）、最近文章列表
- **文章管理**：文章列表（搜索/分类筛选/状态筛选/分页）、发布/编辑/删除、批量操作（发布/草稿/置顶/删除）
- **富文本编辑**：支持 HTML 正文编辑，图片上传并插入正文
- **分类管理**：后台自行添加、改名、删除分类，分类文章数统计
- **标签管理**：增删改查标签、标签文章数统计、重命名自动同步所有文章
- **用户管理**：用户列表、添加/编辑/删除用户、禁用/启用账号、批量操作
- **友链管理**：友链增删改查、审核状态、头像上传、排序
- **留言管理**：关键词过滤、留言审核、状态筛选、位置筛选、批量操作、管理员回复
- **投稿审核**：审核前台用户投稿，通过/拒绝/附原因
- **媒体库**：已上传文件管理、按文件夹筛选、复制链接、删除文件
- **广告管理**：广告位管理（首页/文章页/族谱页/友链页/关于页），支持图片/HTML/文字三种类型，统计点击量
- **缓存管理**：缓存统计、一键清除、分类清除、Cloudflare 缓存集成
- **族谱管理**：族谱人物增删改查、简介设置、密码申请审核、人物提交审核
- **站点设置**：网站名称、Logo、关于页面 HTML、底部文字、默认封面图、显示模式配置、联系方式、赞助支持、维护模式
- **数据管理**：一键导出全部数据备份（JSON 格式）
- **管理员认证**：JWT 认证，密码 bcrypt 加密

### 技术特性

- **数据安全**：数据库文件损坏自动备份并重建，原子写入防止数据丢失
- **API 缓存**：GET 请求缓存机制，缓存键包含查询参数，写操作自动清除缓存
- **深度性能优化**：statSync 节流、N+1 查询消除、单次遍历统计、DOM 更新 requestAnimationFrame、CSS contain/will-change
- **错误处理**：全局错误处理器、404 兜底路由、认证失败自动跳转登录
- **状态同步**：登录用户点赞/收藏实时同步服务器，未登录用户 localStorage 保存，登录后自动合并
- **防闪烁**：页面加载前内联脚本设置主题色/暗黑模式/语言，避免渲染闪烁
- **Cloudflare 部署**：支持 Cloudflare Workers + D1 数据库 + R2 存储

## 本地运行

```bash
npm install
npm start
```

访问：

- 前台：`http://localhost:3000`
- 后台：`http://localhost:3000/admin`

默认后台账号：

- 用户名：`admin`
- 密码：`admin123`

首次启动时会自动创建本地数据库 `data/db.json`。

## 项目结构

```
maishi/
├── server.js              # Express 后端服务（API + 静态文件）
├── package.json           # 项目依赖与脚本
├── wrangler.toml          # Cloudflare Workers 配置
├── data/db.json           # 本地 JSON 数据库（自动生成）
├── uploads/               # 用户上传文件（自动生成）
├── public/                # 前台静态文件
│   ├── index.html         # 首页
│   ├── post.html          # 文章详情页
│   ├── genealogy.html     # 族谱大树图谱页
│   ├── friends.html       # 友链页
│   ├── about.html         # 关于页（含联系我们/赞助支持）
│   ├── login.html         # 用户登录页
│   ├── register.html      # 用户注册页
│   ├── profile.html       # 个人中心页
│   ├── css/style.css      # 前台样式
│   ├── js/main.js         # 前台主逻辑
│   ├── js/ads.js          # 广告位加载与渲染
│   ├── js/genealogy.js    # 族谱大树图谱逻辑
│   └── js/toolbar.js      # 主题/语言/暗黑模式工具栏
├── admin/                 # 后台管理静态文件
│   ├── index.html         # 后台管理主页
│   ├── login.html         # 后台登录页
│   ├── css/admin.css      # 后台样式
│   └── js/admin.js        # 后台主逻辑
├── workers/api.js         # Cloudflare Worker 入口
├── d1/schema.sql          # D1 数据库初始化（含族谱数据）
└── scripts/build-cloudflare.js  # Cloudflare 构建脚本
```

## Cloudflare 部署

请查看 [Cloudflare 部署说明](./CLOUDFLARE_DEPLOY.md)。

重要说明：当前项目完整版使用 Express、JSON 文件数据库和本地上传目录。Cloudflare Pages 只能直接托管静态前台，不能完整运行后台、登录、上传和留言接口。完整版可通过 Node 服务部署后接入 Cloudflare 域名/CDN/Tunnel；如需真正 100% 运行在 Cloudflare Workers，需要把数据层迁移到 D1，把上传迁移到 R2。
